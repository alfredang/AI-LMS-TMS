# Training Provider User Guide

Complete guide for training provider administrators using AI-LMS-TMS.

[Back to Home](./)

---

## Overview

As a **Training Provider** administrator, you have oversight of your organization's training operations. You can view analytics, monitor performance metrics, customize branding, and manage organizational settings. This role provides strategic visibility into training delivery and business performance.

---

## Getting Started

### Logging In

1. Navigate to the AI-LMS-TMS platform
2. Enter your registered email address
3. Click **"Send OTP"** to receive a verification code
4. Enter the 6-digit OTP sent to your email
5. Click **"Verify & Login"**

### First-Time Setup

Configure your training provider profile:

1. Click on your profile icon
2. Select **"Profile"**
3. Complete organization details:
   - Organization name
   - UEN (Unique Entity Number)
   - Contact information
   - Address
4. Upload company logo
5. Click **"Save"**

## Branding & Customization

### Company Logo

Upload and manage your organization's logo:

1. Go to **Profile**
2. Click on the logo area
3. Click **"Upload Logo"**
4. Select image file (PNG or JPG recommended)
5. Preview the logo
6. Click **"Save"**

**Logo Requirements:**
- Format: PNG, JPG, or SVG
- Recommended size: 200x60 pixels
- Maximum file size: 2MB
- Transparent background recommended for PNG

### Company Shortname

Set a short display name:

1. Go to **Profile**
2. Find **"Company Shortname"** field
3. Enter abbreviated name (e.g., "TI" for "Tertiary Infotech")
4. Click **"Save"**

This appears in:
- Navigation header
- Reports
- Certificates

### Color Scheme

Customize platform colors to match your brand:

1. Go to **Profile**
2. Find **"Color Scheme"** section
3. Configure colors:

| Color Setting | Usage |
|---------------|-------|
| **Primary Color** | Buttons, links, highlights |
| **Secondary Color** | Accents, backgrounds |
| **Header Color** | Navigation bar |
| **Text Color** | Body text |

4. Preview changes
5. Click **"Save"**

**Tips:**
- Use colors from your brand guidelines
- Ensure sufficient contrast for readability
- Test on different screens

## SSG Integration Overview

### Understanding SSG Integration

As a Singapore-registered training provider, you can integrate with SkillsFuture Singapore (SSG) for:

- **Course Registration**: Register courses with SSG
- **Grant Applications**: Apply for training grants
- **Enrollment Submission**: Report learner enrollments
- **Assessment Reporting**: Submit competency outcomes
- **Claims Processing**: Submit funding claims

> **Note**: Detailed SSG operations are managed through the Admin role. Contact your admin for specific SSG-related tasks.

### Monitoring SSG Status

View SSG-related metrics in your dashboard:
- Grants applied vs approved
- Claims submitted vs paid
- Pending submissions
- Compliance status

## Troubleshooting

### Common Issues

**Analytics not loading?**
- Refresh the page
- Check internet connection
- Clear browser cache
- Try a different browser

**Logo not displaying correctly?**
- Verify image format (PNG/JPG)
- Check file size (under 2MB)
- Ensure correct dimensions
- Try re-uploading

**Color scheme not applying?**
- Refresh the page after saving
- Clear browser cache
- Check color code format (#XXXXXX)
- Verify all required colors are set

**Reports not generating?**
- Check date range selection
- Verify data exists for the period
- Try a smaller date range
- Contact support if issues persist
