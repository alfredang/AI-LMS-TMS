# Trainer User Guide

Complete guide for trainers using AI-LMS-TMS.

[Back to Home](./)

---

## Overview

As a **Trainer**, you are responsible for delivering courses, managing assessments, and guiding learners through their learning journey. The platform provides tools to view your assigned classes, grade submissions, and create AI-assisted training content.

---

## Getting Started

### Logging In

1. Navigate to the AI-LMS-TMS platform
2. Enter your registered email address
3. Click **"Send OTP"** to receive a verification code
4. Enter the 6-digit OTP sent to your email
5. Click **"Verify & Login"**

### First-Time Profile Setup

Complete your trainer profile with professional information:

1. Click on your profile icon
2. Select **"Profile"**
3. Fill in your details:
   - Full Name
   - Contact Number
   - Email
   - Areas of Expertise
   - Qualifications
   - Certifications
   - Work Experience
4. Upload your CV (optional)
5. Click **"Save"**

## My Classes

### Viewing Assigned Classes

1. Click **"My Classes"** in the navigation
2. View all course runs assigned to you
3. Each class card shows:
   - Course name
   - Course run dates
   - Number of enrolled learners
   - Class status (Upcoming, Ongoing, Completed)

### Filtering Classes

Use filters to find specific classes:
- **Status**: Upcoming, Ongoing, Completed
- **Course Type**: WSQ, IBF, General
- **Date Range**: Filter by date

### Accessing Class Details

1. Click on a class card
2. View comprehensive class information:
   - Course overview and objectives
   - Learning outcomes
   - Session schedule
   - Enrolled learners list
   - Assessment details

## Managing Assessments

### Viewing Assessments

1. Navigate to your class
2. Click the **"Assessments"** tab
3. View all assessments:
   - Assessment name
   - Category (Written, Oral, Practical)
   - Due date
   - Submission count
   - Publish status

### Publishing Assessments

Control when learners can see and submit assessments:

1. Go to the assessment
2. Toggle the **"Published"** switch
3. **Published**: Learners can view and submit
4. **Unpublished**: Hidden from learners

> **Tip**: Publish assessments strategically based on your teaching schedule.

### Assessment Categories

| Category | Examples |
|----------|----------|
| **Written** | Essays, case study analysis, reports |
| **Oral** | Presentations, verbal Q&A, discussions |
| **Practical** | Demonstrations, projects, role plays |

## Grading Submissions

### Viewing Submissions

1. Go to the assessment
2. Click **"View Submissions"**
3. See the list of learner submissions:
   - Learner name
   - Submission date/time
   - Status (Pending, Graded)
   - Grade (if assigned)

### Grading a Submission

1. Click on a submission to open it
2. Review the learner's work:
   - Read text responses
   - Download submitted files
3. Assign a grade:
   - Enter score or select grade
   - Add feedback comments
4. Click **"Submit Grade"**

### Grading Tips

- **Be Consistent**: Use the rubric provided
- **Provide Feedback**: Help learners understand their strengths and areas for improvement
- **Grade Timely**: Meet grading deadlines for learner progress

### Bulk Actions

For multiple submissions:
1. Select submissions using checkboxes
2. Apply bulk actions:
   - Export submissions
   - Mark as reviewed

## Trainer GenAI Authoring

### Overview

The AI-powered authoring tool helps you create professional training content quickly and efficiently.

### Accessing GenAI Tools

1. Click **"Trainer GenAI Authoring"** in navigation
2. Select the type of content to generate
3. Provide input parameters
4. Generate and customize content

### Content Types You Can Generate

| Content Type | Description |
|-------------|-------------|
| **Lesson Plans** | Structured teaching outlines with activities |
| **Case Studies** | Real-world scenarios for discussion |
| **Role Play Scenarios** | Interactive exercises for learners |
| **Assessment Questions** | Written, oral, or practical assessments |
| **Mind Maps** | Visual concept organizers |
| **Discussion Topics** | Facilitation questions and prompts |

### How to Generate Content

1. Select content type
2. Enter the topic or subject matter
3. Specify parameters:
   - Difficulty level
   - Duration
   - Learning objectives
4. Click **"Generate"**
5. Review and edit the generated content
6. Save or export for use

### Best Practices

- **Review Generated Content**: Always verify AI-generated content for accuracy
- **Customize**: Adapt content to your teaching style
- **Iterate**: Generate multiple versions and combine the best parts

## Troubleshooting

### Common Issues

**Can't see my assigned classes?**
- Contact your administrator to verify assignment
- Refresh the page
- Check if class dates are correct

**Submissions not appearing?**
- Ensure assessment is published
- Check the submission deadline hasn't passed
- Verify learners are enrolled

**Can't publish assessment?**
- Check you have trainer permissions
- Verify you're assigned to the class
- Contact support if issues persist

**Materials not downloading?**
- Check your internet connection
- Try a different browser
- Verify file exists in the system
