# User Guides

Comprehensive guides for each user role in AI-LMS-TMS.

Select a guide from the menu to learn how to use the system based on your role.

---

## Available Guides

| Role | Description |
|------|-------------|
| **Learner** | Enroll in courses, track progress, submit assessments, earn certificates |
| **Trainer** | Manage assigned classes, grade submissions, use GenAI authoring tools |
| **Developer** | Create courses, design content, use AI-powered content generation |
| **Admin** | System administration, class management, SSG/TPG integration |
| **Training Provider** | Analytics dashboard, branding, organizational settings |

---

## Quick Role Overview

### Learner
As a learner, you can browse courses, enroll in course runs, track your learning progress, submit assessments, and download certificates upon completion.

### Trainer
As a trainer, you have access to your assigned classes, can view enrolled learners, grade submissions, and use AI-powered tools to create training content.

### Developer
As a course developer, you can create and edit course templates, design learning units and assessments, and use GenAI tools to generate professional content.

### Admin
As an administrator, you have full control over the system including user management, class scheduling, trainer assignments, and SSG API integration.

### Training Provider
As a training provider administrator, you can view analytics, customize branding, manage organizational settings, and monitor business metrics.
