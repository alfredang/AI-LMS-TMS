Learner guide: AI workflow basics

SAMPLE COURSE MATERIAL

Learning objective

Describe a simple AI-assisted workflow with an explicit human review step.

Worked example

Input: an enquiry about a course schedule. Reference: the approved class calendar. Output: a short draft containing the correct dates and a link to the course. Review: compare each date with the calendar before sending.

Checklist

  • Use only approved source material.
  • Remove unnecessary personal information.
  • State what should happen when information is missing.
  • Check the final response against the source.
